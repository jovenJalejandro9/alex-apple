# Guía de estilo · Apple-inspired (Alex)

Dirección visual tomada del estudio de apple.com (nov 2026). No usa logos ni iconos Apple.

## Carácter
Producto editorial / confianza sin ruido. Capítulos blanco/gris/negro, tipografía sistema, CTAs azul cápsula.

## Color
| Uso | Valor |
|---|---|
| Fondo | `#ffffff` / superficie `#f5f5f7` |
| Texto | `#1d1d1f` |
| Muted | `#6e6e73` |
| CTA | `#0071e3` |
| Link | `#0066cc` / dark `#2997ff` |
| Capítulo oscuro | `#000000` |

## Tipografía
`-apple-system, BlinkMacSystemFont` + Inter fallback. H1 600, body 400, subtítulos grandes ligeros.

## Motivos
Hero centrado, foto como producto, cards grises suaves, nav 44 px. Sin mesh Stripe.

## CV A4
Mucho aire, cabecera centrada con foto circular, azul solo en links/cargos, experiencia alineada a izquierda.
